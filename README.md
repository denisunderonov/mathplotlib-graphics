# Matplotlib Graphics

Небольшой проект по визуализации данных на Python с использованием **Matplotlib**.

В проекте реализованы основные виды графиков:

* линейные графики;
* линейные графики со стилями;
* столбчатые диаграммы;
* гистограммы;
* boxplot;
* scatter matrix.
